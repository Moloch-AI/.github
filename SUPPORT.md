# Getting help

| You need help with | Go to |
| --- | --- |
| A bug or missing feature in an SDK, the CLI, the playground or an example | An issue in that repository |
| How the API behaves: parameters, streaming, errors, limits | The [API documentation](https://molochai.dev/docs), starting with [errors and troubleshooting](https://molochai.dev/docs/errors) |
| Concepts, deployment options and common problems | The [uncensored-ai](https://github.com/Moloch-AI/uncensored-ai) guide |
| Your account, API keys, billing or a problem with the hosted API | [molochai.dev/contact](https://molochai.dev/contact) |
| A security vulnerability | The [security policy](SECURITY.md). Do not open a public issue |

When you report an API problem, include the HTTP status, the full error body (most errors have a `type`, and upstream errors include a `request_id`), the model id, whether you were streaming, and the approximate time with your timezone. Never include an API key.
