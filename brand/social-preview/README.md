# Social preview images

One 1280×640 image per repository, shown when a repository link is shared (Slack, X, LinkedIn,
Discord, Reddit). Brand colors and fonts from the MolochAI kit: background `#100E12`, accent
`#FF6A3D`, Instrument Sans and JetBrains Mono.

GitHub has no API for this, so each image is uploaded by hand, once per repository:

1. Open the repository, then **Settings** (you need admin access).
2. In **General**, under **Social preview**, choose **Edit**, then **Upload an image…**.
3. Pick the file with the repository's name from this folder.
